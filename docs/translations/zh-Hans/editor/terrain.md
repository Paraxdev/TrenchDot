# 地形 { #terrain }

地形是一大片高度网格，你可以像捏黏土一样雕刻它，上面最多能刷四种纹理。丘陵、海滩和山谷这类开阔的地面适合用它，靠手工一块块做笔刷会慢得没完。

这一页讲怎样创建地形，以及怎样用雕刻工具（G）塑形。给它贴纹理见[地形图层](terrain-layers.md)和[地形绘制](terrain-painting.md)。

地形创建之后还能继续扩大，每个轴向最多 2048 个单元格，可以用检查器里的**大小**区块（[更改大小](#changing-the-size)），也可以在 2D 视图里用选择工具拖动它的边（[拖动边](#dragging-an-edge)）。它最多带四个图层，用[混合工具](terrain-painting.md)来绘制。

因为地面是高度场，它不能向自身折叠，要做那样的形状请看[洞穴与悬垂](caves-overhangs.md)。

## 创建地形 { #creating-a-terrain }

1. 打开对话框

    在菜单栏里选 *地形 > 创建地形…*。

    ![地形菜单已展开，鼠标停在创建地形…上](../assets/terrain/menu-create-terrain.png)

2. 选一个大小

    **分辨率**和**单元大小**决定它有多大，它们下面的**大小**一行会以单位和米显示结果。默认的 129 x 129 个顶点配 64 单位的单元，得到 8192 单位，也就是 256 米。参见下面的[选择单元大小](#picking-the-cell-size)。

    ![创建地形对话框，保持默认值：129 x 129，64 u 的单元，丘陵，以及四个图层字段](../assets/terrain/create-terrain-dialog.png)

3. （可选）选一个起始形状

    **形状**是你起步用的地面。默认是丘陵，其他有平地、山地、岛屿、山谷和山脊。它下面的几行用来调整生成地面所用的噪声：

    | 行 | 含义 |
    | --- | --- |
    | 高度 | 地面能有多高，默认 512 u |
    | 特征大小 | 一座丘陵或一道山谷有多宽，默认 2048 u |
    | 倍频 / 粗糙度 | 倍频越多、粗糙度越高，上面叠加的小起伏就越细 |
    | 侵蚀 | 让陡坡坍塌的遍数，默认 20 |
    | 种子 | 同一个种子会再次得到同样的地面 |

    **高度图**旁边的**导入 PNG…**改为读取一张灰度图（PNG、TGA 或 BMP），越亮的像素越高，最高到**高度**。**清除**会回到生成的形状。形状和高度图只在这里创建时有效。

4. （可选）选好图层

    **基础图层**、**坡面图层**、**峰顶图层**和**低地图层**是地形的四种纹理，起初是 `dev/green`、`dev/grey`、`dev/blue` 和 `dev/orange`。**用当前**会放入你最后点击的材质，**平铺**是它重复一次所覆盖的单位数。**按坡度和高度绘制图层**默认是勾选的，它会立刻绘制各图层，见[自动绘制](terrain-painting.md#auto-paint)。

5. 点击底部的**创建**

    地形会以 3D 光标为中心，或者在取消勾选 **3D 光标**后，以你输入的**居中**为中心，那个高度就成为地形的零点。你应该会看到新地形被选中，雕刻工具已经激活。

## 选择单元大小 { #picking-the-cell-size }

| 设置 | 含义 |
| --- | --- |
| 分辨率 | 每条边上有多少个顶点，33、65、129、257、513 或 1025 之一。顶点越多，能保存的细节越多，但绘制和雕刻的开销也越大 |
| 单元大小 | 两个相邻顶点之间的距离，单位是地图单位，范围 4 到 1024 |

例如 257 个顶点配 64 单位的单元，得到 16384 单位，也就是 512 米。

两个顶点之间什么都没有，所以单元大小就是地形能容纳的最细的细节。山脉要用大单元，花园则用小的。

选错了？创建地形之后，你随时都可以[改变大小](#changing-the-size)。

检查器里的**区块单元数**（默认 32）会把地形分成方形的块，用于绘制和碰撞。块越小，雕刻时重建得越快，块越大，Godot 里的节点就越少。

## 改变大小 { #changing-the-size }

地形不会被困在你创建时的大小上。你可以在任意一边添加单元格、裁掉单元格，或者改变单元大小，而你已经雕刻好的地面会原样留在地图里原来的位置。

1. 选中地形

    在视图或大纲里点击它。它的**大小**区块在检查器里**原点**的下方。

2. 输入改动

    | 字段 | 在那里输入会怎样 |
    | --- | --- |
    | **单元格数** | 设定沿 X 和 Z 的总数。相对的两边会均匀增减，多出的奇数个单元格归东边或南边 |
    | **北 (-Z)**、**南 (+Z)**、**西 (-X)**、**东 (+X)** | 只改变这一条边。正数会添加那么多单元格，负数会去掉，所以东边填 `+8` 会加 8 个，南边填 `-2` 会裁掉 2 个 |

    ![大小区块，东边添加了 8 个单元格，南边移除了 2 个，之后一行显示结果](../assets/terrain/inspector-size.png)

    这时还什么都没变。你的修改只是草稿，在视图里画成轮廓，**应用**下方的**之后**一行告诉你会得到多少单元格和多大尺寸。

3. 选择新地面的内容

    只要有一条边增长，**新地面**就会出现。**边缘高度**延续最近的边缘，高度和绘制内容都延续，所以地形只是变长了。**零**让新单元格的高度为 0 并使用第一个图层，得到一块可以搭建的平地。第一个新单元格仍会从旧边缘倾斜下降到 0，所以平坦部分从往外一个单元格的地方开始。

4. 点击**应用**

    地形在一步之内完成改变，按 Ctrl+Z 会把它精确地恢复。**重置**则会丢弃草稿。

保留下来的一切都在和之前相同的世界位置：留下的单元格的高度、绘制内容和洞。如果你在西边或北边添加单元格，地形的**原点**会相应地向外移动。

**单元大小**的工作方式不同，它会用新的间距重建网格：

* 地形在地图里的大小会保持到最接近的整数个单元格，所以单元格数也跟着变。高度和绘制内容会在旧顶点之间混合。
* 当大小不是新单元的整数倍时，地形会增大或缩小最多半个单元格，**之后**下方的**为凑成整数个单元格，尺寸改变**一行会告诉你改变了多少。把单元大小改回去并不会撤销这次取整，Ctrl+Z 才会。
* 单元变大会丢掉细节，应用之前检查器会用**细节会丢失**提醒你。单元变小会保留形状，但无法添加原本就不存在的细节。
* 先应用各条边，再应用单元大小。

> [!NOTE]
> 地形沿每个轴有 1 到 2048 个单元格，单元大小在 0.001 到 100000 单位之间。超出这个范围的改动，或者会裁掉所有单元格的改动，会被拒绝并用红色显示原因，**应用**保持灰色。

### 拖动边 { #dragging-an-edge }

在**顶**、**前视**和**侧视**视图里也可以直接更改大小，前提是恰好选中了一块地形，它没有被锁定，也没有选中任何面。用选择工具把指针移到它的一条边上，直到光标变成调整大小的箭头、这条边亮起，然后向外拖动来添加单元格，向内拖动来裁掉单元格。边会吸附到整数个单元格，状态栏会显示新的单元格数。每次拖动是一个步骤，Ctrl+Z 可以撤销。

![在顶视图里，东边向外拖出了四个单元格的地形](../assets/terrain/edge-drag.png)

拖动相当于在这一侧的字段里输入数值并立刻点击**应用**。新地面会延续边缘，就像**边缘高度**那样，而且地形永远不会少于 1 个单元格。

在前视图和侧视图里只能抓住左右两端，因为地面的高度来自雕刻。想要**零**高度的地面或新的单元大小时，请改在**大小**区块里输入。

### 地形上的散布 { #scatter-on-the-terrain }

画在地形上的[散布](scatter.md)在你更改大小时会留在地面上：

* 仍然存在的地面上方的实例会随新的高度升降，所以不会悬空，也不会陷下去。
* 被裁掉的地面上方的实例默认会被移除。有这样的实例时，**应用**下方会出现一个**移除已删除区域上的 n 个散布实例**复选框。如果你打算自己移动它们，就取消勾选，让它们留在原处，悬在空处。
* 向内拖动边时它们总是会被移除，Ctrl+Z 会把它们带回来。
* 被锁定或隐藏的散布集，或者位于被锁定或隐藏的图层里的散布集，会保持原样。

## 雕刻 { #sculpting }

按 G，在左上角工具选项栏的第一个菜单里选一个模式，然后在地形上拖动。它作用于选中的地形，什么都没选时则作用于所有地形。

![雕刻工具的模式菜单在工具选项栏里展开，旁边是半径和强度输入框](../assets/terrain/sculpt-modes.png)

用抬升时，一直按住鼠标键，地面就会在笔刷下不断升高。

![按住抬升并使用 900 单位的笔刷，从岛上堆出一座小山](../assets/terrain/sculpt-raise.gif)

| 模式 | 作用 |
| --- | --- |
| 抬升、降低 | 只要按着按钮，就不断把高度堆高或挖低。点一下会做出一个小凸起 |
| 平滑 | 让每个顶点向它的邻居放松，用来柔化疙瘩和尖锐的山脊 |
| 压平 | 把地面拉到笔画开始处的高度，用来做平台、道路和高地 |
| 噪声 | 加上细小的随机起伏，让平地看起来没那么人工 |
| 梯田 | 把高度吸附到**步长**个单位的台阶上（默认 32），适合做梯田或阶梯状的悬崖。这个字段显示在模式旁边 |
| 绘制 Alpha、擦除 Alpha、绘制图层 | 用来绘制而不是塑形。Alpha 模式是给置换用的，绘制图层则绘制你在模式旁边的**图层**字段里设置的地形图层。在地形上，[混合工具](terrain-painting.md)能更精细地控制这件事 |
| 挖洞、填洞 | 整格整格地挖掉或补回，碰撞也一起处理。适合做洞穴或掩体的入口，见[洞穴与悬垂](caves-overhangs.md) |

Ctrl+滚轮调整笔刷大小，Shift 对调抬升和降低，按住 Ctrl 则不论什么模式都变成平滑。

选项栏里的**强度**字段决定笔刷干活的速度。抬升和降低每点强度每秒移动笔刷中心 8 单位，与**半径**无关，所以默认的 4 每秒堆高 32 单位。做丘陵和岛屿时，把强度调高，不要按住一分钟。

笔刷半径要大于地形的单元大小，更小的笔刷只会推动它下面的那一个顶点（出现这种情况时状态栏会告诉你）。

想重新开始，用 *地形 > 雕刻 > 压平*，或者检查器里的**压平**，把整个选中的地形重设回它的零点高度。

> [!TIP]
> 用大笔刷塑形，每粗糙地走一遍就平滑一次。小笔刷会留下疙瘩。

## 对称 { #symmetry }

想同时雕刻山谷或岛屿的两侧，就打开对称。**雕刻**和**混合**两个工具都有这个控件，它在工具选项栏中，紧跟在**强度**和模式字段之后。

![雕刻工具选项栏里打开的对称菜单，列出关、X、Z 和 X 和 Z](../assets/terrain/symmetry-menu.png)

| 控件 | 作用 |
| --- | --- |
| **对称 关**菜单 | 选 **X** 让西半边和东半边互相镜像，选 **Z** 镜像北和南，选 **X 和 Z** 则两者都镜像。关闭的菜单随后会显示**对称 X**、**对称 Z** 或**对称 X 和 Z** |
| **地形中心**菜单 | 只在对称打开时显示。它决定镜像平面的位置：**地形中心**（每块地形的中间）、**世界原点**或**自定义** |
| **x** 和 **z** 字段 | 只在**自定义**时显示，每个镜像轴一个，是平面的位置，单位是单位。它们一开始就是你刚才用的平面，所以不会跳动 |

对称打开时，只要雕刻或混合是当前工具，视图就会画出这些平面，X 是红色轮廓，Z 是蓝色轮廓。每个平面与地面相交的地方有一条线，按下之前，一个较暗的笔刷圆环副本会显示镜像的笔触会落在哪里。

![打开对称 X 和 Z 的 3D 视图，显示两个镜像平面，笔刷圆环在四个象限里都重复出现](../assets/terrain/symmetry-planes.png)

照常拖动。每一笔都会应用在光标处和它的镜像位置，整条笔划仍然是一个撤销步骤。落在平面上的一笔，或者和自己的镜像重叠的一笔，只算一次，所以那里的地面不会升高两倍。噪声、混合噪声和喷洒得到的是真正的镜像，而不是新的随机图案。

使用**地形中心**时，每块地形绕自己的中心镜像，置换则绕它们所有的共同中心镜像。雕刻和混合共用这个设置。每个地图标签页各自保留设置，新建或打开的地图沿用你正在用的设置，但**自定义**会回到**地形中心**，每次启动编辑器时它都会重新回到关闭。

> [!TIP]
> 想跨越并排的几块地形镜像，或者绕一个不是它们中心的位置镜像，请用**世界原点**或**自定义**。把平面放在一条顶点线上，或者正好放在两条之间，就能完全吻合，其他位置只能近似镜像。

<div class="td-mcp" markdown>

`sculpt` 操作、`blend` 工具和 `terrain_edit`（`sculpt`、`sculpt_path`、`paint_path` 和带 `center` 的 `holes`）都接受 `symmetry` 参数，取值是 `off`、`x`、`z`、`xz`，或者对象 `{axes, center, x, z}`。`set_editor` 设置工具栏使用的那个，`get_state` 会报告它，见 [MCP](../mcp.md)。

## 在 Godot 里 { #in-godot }

每个地形都会变成一个 `TrenchDotTerrain` 节点，它是一个 `StaticBody3D`（Godot 里用于永远不会移动的实心地面的节点），碰撞与它绘制出来的样子一致。在游戏代码里，`height_at(x, z)` 会返回某个局部位置的地面高度，在运行时把东西放到地面上很方便。

## MCP { #mcp }

`terrain_edit` 工具的 `sculpt` 操作会施加一次点按，它的强度就是这一下把中心移动多远，同样与半径无关。以强度 4 持续一秒的笔画，相当于一次强度 32 的点按。

同样的大小改动是带 `op: "resize"` 的 `terrain_edit`，它接受以单元格计的 `north`、`south`、`west` 和 `east`，或者 `cells: [x, z]`，以及 `cell_size`。加上 `dry_run: true` 可以先读取结果的单元格数、边界、`scatter_removed` 和 `detail_lost`。`fill` 是 `edge` 或 `zero`，`scatter` 是 `drop` 或 `keep`，和检查器里一样。限制见 [MCP](../mcp.md)。

</div>
