# ブラシとCSG { #brushes-and-csg }

ブラシは、レベルの大部分を組み上げる材料です。すばやく描けて、グリッドにきれいにスナップし、Godotでは対応するコリジョン付きのメッシュになります。ここで説明する操作は、別のツールを挙げている節を除いて、すべて**選択**ツール（Q）で行います。

## 描く、動かす { #draw-and-move }

選択範囲の外のどこでも、どのビューでもドラッグすると、ボックスがマウスに付いてきます。2Dビューでは、その横にサイズが表示されます。3Dビューでは、カーソルの下の面から始まり、厚さはグリッド1ステップ分です。2Dビューでは、選択中のものの奥行きになります。HammerやTrenchBroomと同じです。床を選択していれば、トップビューだけで同じ高さの床をさらに描けます。何も選択していないときは、最後に描いたブラシの奥行きになり、最初の1つだけは128ユニットです。常に最後のブラシの奥行きを使いたいときは、*ファイル > 環境設定*で*新しいブラシの奥行きを選択から取る*のチェックを外します。

![環境設定で、新しいブラシの奥行きを選択から取るチェックボックスがオンになっている。キーマッププリセットの下にある](../assets/brushes/preferences-depth-from-selection.png)

![3Dでボックスを描いているときの4つのビュー。新しいボックスは144×144ユニットで、厚さはグリッド1ステップ、16ユニット](../assets/brushes/draw-box-3d.png)

ブラシを選択したら、動かせます。

| 入力 | 結果 |
| --- | --- |
| 選択範囲をドラッグ | 移動する。Shiftで主軸に固定 |
| Ctrl+選択範囲をドラッグ | コピーを移動する。元のものは残る |
| Alt+選択範囲をドラッグ（3D） | 垂直に移動する。選択範囲の外から始めたAlt+ドラッグは、カメラを周回させる |
| 矢印キー、Page Up、Page Down | グリッド1ステップ分だけずらす |
| `[`と`]` | グリッドを半分にする、2倍にする |

3Dでは、選択範囲に移動、回転、拡大縮小のギズモも付きます。回転は15°ごとにスナップし、Shiftを押すと1°刻みになります。邪魔なときは、*表示 > トランスフォームギズモ*でオフにできます。

## 正確な位置とサイズ { #exact-position-and-size }

ドアの切り抜き用ブラシを壁とぴったり同じ奥行きにしたいときなど、正確な数値が欲しい場面があります。ブラシを選んで、右側の**インスペクター**に数値を入力してください。

![ブラシを1つ選択したインスペクター。位置とサイズの欄が表示されている](../assets/brushes/inspector-position-size.png)

位置は、X、Y、Zがそれぞれ最小になる角、つまり多くの場合グリッド上にある角です。新しいサイズは、その角から離れる向きに選択範囲を広げるので、位置は動きません。スナップがオンの間は、欄をドラッグするとグリッド単位で変わり、入力した値はそのまま保たれます。同じ欄は、メッシュ、ブラシエンティティ、複数のオブジェクトの選択でも表示されます。

## 形を変える { #reshape }

選択したブラシは、選択ツールのままで形を変えられます。

| 入力 | 結果 |
| --- | --- |
| 選択した面をShift+ドラッグ（3D） | その面を押したり引いたりする |
| 選択した面をCtrl+Shift+ドラッグ（3D） | そこから新しいブラシを押し出す |
| 選択範囲のエッジをドラッグ（2D） | サイズを変える。エッジが黄色く光り、ドラッグでサイズが変わる位置ではカーソルが変わる |

スナップがオンの間は、ドラッグした面はグリッド線の上に乗ります。ブラシがもともとグリッドから外れていた場合も同じです。斜めの面は、代わりにグリッド単位で動きます。

![3Dビューで、選択したボックスの側面をShift+ドラッグしているところ。ボックスがグリッド単位で伸びる](../assets/brushes/push-face.gif)

スロープ、傾斜路、斜めの壁には、Cを押して**クリップ**ツールを使います。

1. 切断線に沿って、2〜3か所をクリックします。点はグリッドにスナップし、3Dではクリックした面の上に置かれます。
2. Tabを押して、残す側（手前、奥、または両方の半分）を選びます。ビューの下部のテキストに、今どれが有効かが表示されます。
3. Enterを押して切断します。クリックを間違えたら、Backspaceで最後の点を取り除けます。

![正面ビューで、ボックスの上の角をまたぐ2つの点を置いたクリップツール。切断線は3Dビューにも表示されている](../assets/brushes/clip-points.png)

角を1つずつドラッグするには、Vを押して**頂点**ツールにするか、ブラシを選んだ状態でTabを押します。角にハンドルが表示され、エッジの中点と面の中心には小さな青い点が出ます。点をクリックして選択するか、ブラシから離れる向きにドラッグして、そこに角を追加します。Deleteで、選択した頂点が削除されます。

![クリップしたボックスの頂点ツール。黄色の角のハンドルと、エッジや面の上の青い点](../assets/brushes/vertex-handles.png)

> [!NOTE]
> ブラシにはへこみを作れないので、へこみができる移動は拒否されます。移動先に赤いゴーストが表示され、ステータスバーに一行出ます。代わりに点を外側へ引くか、へこみや張り出しが必要なら、ブラシを[メッシュ](meshes.md)に変換してください。

## 回転、拡大縮小、計測 { #rotate-scale-and-measure }

| ツール | 入力 | 結果 |
| --- | --- | --- |
| **回転**（R） | 選択範囲の周りのリングをドラッグ | 15°刻みで回転し、Shiftを押すと1°刻み。2Dビューには、そのビューが見ている軸の周りにリングが1つあります |
| **スケール**（T） | 選択範囲の境界のハンドルをドラッグ | グリッド単位でサイズを変える。Altを押すと両側が同時に動くので、中心はそのままになる。3Dビューには各辺にハンドルがあります |
| **計測**（M） | ドラッグするか、2点をクリック | 距離をユニットとメートルで表示し、ビューの下部にそのX、Y、Z、水平方向の成分を表示する |

![3Dビューの計測ツール。230.76 u (7.21 m)と書かれた線と、下部のX、Y、Zの成分](../assets/brushes/measure.png)

## 形状ジェネレーター { #shape-generator }

円柱、アーチ、階段、屋根など、手で描くと大量のブラシが必要になる形には、形状ジェネレーターを使います。

1. 形を置きたい場所にボックスを描き、選択したままにします。
2. *ブラシ > 形状ジェネレーター…*（Ctrl+Shift+B）を開きます。
3. **形状**とそのオプションを選びます。ダイアログには、埋める範囲と、選択範囲が置き換わることが表示されます。
4. **作成**をクリックします。

![円柱、16辺、Y軸に設定した形状ジェネレーターのダイアログ。128×192×128の選択範囲を埋める](../assets/brushes/shape-generator.png)

![左は選択したボックス、右はそれと置き換わった16辺の円柱](../assets/brushes/shape-generator-box-to-cylinder.png)

円柱と円錐は、初期状態では立った向きになります。パイプ、丸太、梁のように寝かせたいときは、あとから回転させる代わりに、**軸**で**X**か**Z**を選べば、同じボックスの中で横向きにできます。トーラス、アーチの壁、切妻屋根、尖塔、グリッドは、常に[メッシュ](meshes.md)として作られます。円柱、円錐、球も**編集可能なメッシュとして作成**でメッシュにでき、そのうえで**スムースシェーディング**を使うと丸みが出ます。**テキスト**の形状は、看板や床の文字のために、ブラシで作ったブロック文字を組み上げます。

**岩**は、ボックスを石で満たします。**粗さ**はどれだけごつごつさせるかを決め、**ファセット**は平らな面を削り込み、**平らな底**は下側を平らに切って地面に置けるようにします。**シード**を変えると、同じ種類の別の石になります。ブラシにすると、岩はCSGで使えて、ほかのブラシと同じように衝突する、1つの凸形のローポリな石になります。**編集可能なメッシュとして作成**を使うと、くぼみや張り出しが残り、**詳細**で表面をどれだけ細かく分割するかを決めます。

![形状ジェネレーターを岩の編集可能なメッシュに設定した画面。粗さ0.5、ファセット5、平らな底0.3、詳細3、シード1](../assets/brushes/shape-generator-rock.png)

![灰色の床に置かれた5つのオレンジ色の岩。手前の3つはごつごつしたメッシュで、奥の2つはファセットのあるブラシの岩](../assets/brushes/shape-generator-rocks.png)

## 面をスイープ { #sweep-faces }

通路やパイプ、トリムを角の向こうまで延ばすには、その端の面をスイープします。それぞれの面がパスに沿って押し出され、元のブラシのマテリアルを持つブラシの列を残します。

1. 3Dビューで、延ばしたい端の面をShift+クリックし、ほかの面はCtrl+Shift+クリックで加えます。たとえば通路の床と両側の壁です。
2. *ブラシ > 面をスイープ…*を開きます。作られるブラシが、シアンの輪郭で表示されます。
3. **直線**、**円弧**、**S字**のいずれかを選び、パスを設定します。**半径**はカーブの中心から面の中央まで測り、**方向**は面の側から見た向きです。
4. **作成**をクリックします。新しいブラシが選択され、元のブラシのグループやエンティティに加わるので、`func_door`の端をスイープするとドアが長くなります。

![円弧、半径128、角度90、方向は右、8セグメントに設定した面をスイープのダイアログ。32個のブラシができる](../assets/brushes/sweep-faces-dialog.png)

![暗い色の床と2枚のオレンジ色の壁でできた通路。直線、90度の円弧、再び直線の順にスイープしている](../assets/brushes/sweep-faces-corridor.png)

**セグメント**を増やすと、カーブがなめらかになります。**上昇**は端を持ち上げるので、上昇のある円弧はらせん状のスロープになります。**ねじり**は面をその場で回転させ、**終端スケール**は途中で面を拡大または縮小します。面の幅より小さい半径の円弧は、内側で折り返してしまうので、ダイアログは代わりに使える最小の半径を表示します。選んだ面はすべて、平均した向きに沿って同じ方向へ進むので、通路の端のように、同じ向きを向いた面を選んでください。互いに角度のついた面は、斜めに伸びてしまいます。

<div class="td-mcp" markdown>

MCPツール`sweep_faces`は同じ設定を受け取り、面は`[brush id, face index]`のペアで指定するか、指定しない場合は選択中の面が使われます。

## CSG { #csg }

CSGの操作は*ブラシ > CSG*にあり、2つの設定もここにあります。

![ブラシメニューでCSGサブメニューが開き、減算、凸マージ、交差、中空化がショートカットとともに並び、その下にくり抜いた面は対象のマテリアルを保つのチェックボックスと壁の厚さの欄がある](../assets/brushes/menu-brush-csg.png)

4つとも、ツールバーのスナップボタンとUVロックボタンの右側にボタンがあります。

![ツールバーの4つのCSGボタン。凸マージにカーソルを合わせ、ツールチップが出ている](../assets/brushes/toolbar-csg.png)

| 操作 | キー | 結果 |
| --- | --- | --- |
| 減算 | Ctrl+K | 触れているすべてのブラシから選択範囲をくり抜き、選択範囲を削除する。ほかのブラシに触れていない選択範囲は残り、ステータスバーにそう表示される |
| 中空化 | Ctrl+Shift+K | ブラシを、元の体積の周りの壁に変える。厚さは、同じメニューの*壁の厚さ*を変えなければ16ユニット。壁2枚分に足りない薄いブラシは、そのまま残る |
| 凸マージ | Ctrl+M | 選択範囲を、それを包む1つの凸形のブラシにまとめる |
| 交差 | Ctrl+L | 選択したブラシが重なっている部分だけを残す |

出入り口や窓をあけるには、穴の位置にブラシを置いて減算します。[はじめの一歩](../getting-started.md)で、1つあけるところを順に案内しています。切断で現れた面は、同じメニューの*くり抜いた面は対象のマテリアルを保つ*にチェックを入れない限り、切り抜きに使ったブラシのマテリアルになります。

## ディスプレイスメント { #displacements }

がれきの斜面のような、ブラシで作るレベルの中のでこぼこした地面には、面をディスプレイスメントに変えて、スカルプトできます。

1. 四角形の面をShift+クリックするか、ブラシを選んでその上面を使います。
2. *ブラシ > ディスプレイスメント*を開き、**作成**のエントリーのどれかを選びます。パワーが高いほど、グリッドが細かくなります。
3. **スカルプト**ツール（G）が自動でオンになるので、面の上をドラッグして形を作ります。

![ブラシメニューでディスプレイスメントサブメニューが開き、作成、パワー2 (5x5)、作成、パワー3 (9x9)、作成、パワー4 (17x17)、続いてディスプレイスメントを縫合、ディスプレイスメントを削除が並ぶ](../assets/brushes/menu-brush-displacement.png)

屋外の広いエリアには、[地形](terrain.md)のほうが向いています。
