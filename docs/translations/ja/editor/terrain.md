# 地形 { #terrain }

地形は、粘土のようにスカルプトできる高さの大きなグリッドで、その上に最大4枚のテクスチャをペイントできます。丘、砂浜、谷のような広い地面に使ってください。そうした場所でブラシを手で整えていたら、いつまでたっても終わりません。

このページでは、地形を作ることと、スカルプトツール（G）で形を整えることを説明します。テクスチャの貼り方は[地形レイヤー](terrain-layers.md)と[地形のペイント](terrain-painting.md)にあります。

地形は作成したあとで広げることもでき、各軸に沿って最大2048セルまで増やせます。インスペクターの**サイズ**ブロックを使う方法（[サイズを変える](#changing-the-size)）と、2Dビューで選択ツールを使って辺をドラッグする方法（[辺をドラッグする](#dragging-an-edge)）があります。レイヤーは最大4枚まで持て、[ブレンドツール](terrain-painting.md)でペイントします。

地面はハイトフィールドなので、自分自身の上に折り重なることはできません。代わりの方法は[洞窟とオーバーハング](caves-overhangs.md)を見てください。

## 地形を作る { #creating-a-terrain }

1. ダイアログを開く

    メニューバーの*地形 > 地形を作成…*を開きます。

    ![地形メニューを開き、地形を作成…にカーソルを重ねたところ](../assets/terrain/menu-create-terrain.png)

2. サイズを決める

    **解像度**と**セルサイズ**で大きさが決まり、その下の**サイズ**の行に、結果がユニットとメートルで表示されます。デフォルトは頂点129 x 129、セルが64ユニットで、8192ユニット、256mになります。下の[セルサイズを決める](#picking-the-cell-size)を参照してください。

    ![デフォルトの状態の地形を作成ダイアログ。129 x 129、セル64 u、丘、4つのレイヤー欄が並んでいる](../assets/terrain/create-terrain-dialog.png)

3. （任意）最初の形を選ぶ

    **形状**は、出発点になる地面です。既定は丘で、ほかに平坦、山、島、谷、尾根があります。その下の行は、地面のもとになるノイズを調整します。

    | 行 | 意味 |
    | --- | --- |
    | 高さ | 地面がどれくらい高くなるか。既定は512 u |
    | 地形の大きさ | 丘や谷1つの幅。既定は2048 u |
    | オクターブ / 粗さ | オクターブを増やして粗さを上げると、その上に細かい凹凸が加わります |
    | 侵食 | 急な斜面を崩す回数。既定は20 |
    | シード | 同じシードなら、同じ地面がもう一度できます |

    **ハイトマップ**の隣の**PNGをインポート…**は、代わりにグレースケール画像（PNG、TGA、BMP）を読み込みます。明るいピクセルほど高くなり、最大で**高さ**までです。**クリア**を押すと、生成した形状に戻ります。形状とハイトマップは、作成時のここだけで使えます。

4. （任意）レイヤーを選ぶ

    **ベースレイヤー**、**斜面レイヤー**、**山頂レイヤー**、**低地レイヤー**が地形の4枚のテクスチャで、最初は`dev/green`、`dev/grey`、`dev/blue`、`dev/orange`になっています。**現在を使用**は、最後にクリックしたマテリアルを入れ、**タイル**は、そのマテリアルの1回の繰り返しが何ユニットにあたるかです。**傾斜と高さでレイヤーをペイント**は既定でオンで、レイヤーをすぐにペイントします。[自動ペイント](terrain-painting.md#auto-paint)を見てください。

5. 下にある**作成**をクリックする

    地形は3Dカーソルを中心に置かれます。**3Dカーソル**のチェックを外すと**中央**に数値を入力でき、その位置が中心になります。その高さが地形のゼロになります。新しい地形が選択され、スカルプトツールがすでに有効になっているはずです。

## セルサイズを決める { #picking-the-cell-size }

| 設定 | 意味 |
| --- | --- |
| 解像度 | 各辺に沿って並ぶ頂点の数。33、65、129、257、513、1025のどれかです。頂点が多いほど細部を保てますが、描画とスカルプトのコストも増えます |
| セルサイズ | となり合う頂点の間の、マップ単位の距離。4から1024まで |

たとえば、頂点257でセルが64ユニットなら、16384ユニット、512mです。

頂点と頂点のあいだには何もないので、セルサイズが地形で表せる最も細かい部分になります。山脈には大きなセルを、庭には小さなセルを選びます。

選び間違えても、地形を作ったあといつでも[サイズを変えられます](#changing-the-size)。

インスペクターの**チャンクのセル数**（既定は32）は、描画とコリジョンのために地形を正方形のかたまりに分けます。チャンクが小さいほどスカルプト中の再構築が速く、大きいほどGodotのノードが少なくなります。

## サイズを変える { #changing-the-size }

地形は作ったときのサイズのままではありません。どの辺にもセルを足したり切り取ったりでき、セルサイズも変えられます。すでにスカルプトした地面は、マップ上のもとの位置にそのまま残ります。

1. 地形を選ぶ

    ビューかアウトライナーで地形をクリックします。インスペクターの**原点**の下に**サイズ**ブロックがあります。

2. 変更を入力する

    | フィールド | 入力するとどうなるか |
    | --- | --- |
    | **セル数** | XとZに沿った合計を決めます。向かい合う両側が均等に伸び縮みし、余る1セルは東か南の辺に入ります |
    | **北 (-Z)**、**南 (+Z)**、**西 (-X)**、**東 (+X)** | その辺だけを変えます。正の数はその数だけセルを足し、負の数は取り除くので、東に`+8`と入れると8セル増え、南に`-2`と入れると2セル切り取られます |

    ![東に8セル足し、南から2セル取り除いたサイズブロックと、結果を示す変更後の行](../assets/terrain/inspector-size.png)

    この時点ではまだ何も変わりません。入力は下書きで、ビューに輪郭として描かれ、**適用**の下の**変更後**の行に、適用後のセル数とサイズが表示されます。

3. 新しい地面の中身を選ぶ

    **新しい地面**は、どれかの辺が伸びると表示されます。**端の高さ**は最寄りの端を高さもペイントも引き継ぐので、地形がそのまま長くなります。**ゼロ**は新しいセルの高さを0にして最初のレイヤーを塗り、建物を置ける平らな場所を作ります。ただし最初の新しいセルは古い端から0まで傾斜するので、平らな部分は1セル外側から始まります。

4. **適用**をクリックする

    地形は1ステップで変わり、Ctrl+Zで正確にもとに戻ります。**リセット**を押すと下書きを捨てます。

残った部分はすべて、前と同じワールド位置にあります。残ったセルの高さ、ペイント、穴も同じです。西か北の辺にセルを足すと、それに合わせて地形の**原点**が外側に動きます。

**セルサイズ**は動き方が違い、新しい間隔でグリッドを作り直します。

* 地形はマップ上の大きさを最も近い整数セルに保つので、セル数も一緒に変わります。高さとペイントは古い頂点のあいだで補間されます。
* 大きさが新しいセルの倍数でないときは、地形が最大で半セル分伸び縮みし、**変更後**の下の**セルを整数に揃えるため、サイズが**の行にその量が表示されます。セルサイズをもとに戻してもこの丸めは戻りませんが、Ctrl+Zなら戻ります。
* セルを大きくすると細部が失われ、適用する前にインスペクターが**細かいディテールが失われます**と警告します。セルを小さくすると形は保たれますが、もともとなかった細部は増えません。
* 辺の変更が先に、セルサイズがそのあとに適用されます。

> [!NOTE]
> 地形のセル数は各軸に沿って1から2048まで、セルサイズは0.001から100000ユニットまでです。この範囲を超える変更や、すべてのセルを切り取ってしまう変更は、理由が赤で表示されて拒否され、**適用**はグレーのままです。

### 辺をドラッグする { #dragging-an-edge }

**上**、**前**、**横**のビューでは、地形がちょうど1つだけ選択されていて、ロックされておらず、面が選択されていなければ、その場でサイズを変えることもできます。選択ツールで地形の辺にポインターを合わせ、カーソルがリサイズの矢印になって辺が光ったら、外へドラッグしてセルを足すか、内へドラッグして切り取ります。辺は整数セルにスナップし、ステータスバーに新しいセル数が表示されます。ドラッグ1回が1ステップで、Ctrl+Zで元に戻せます。

![東の辺を4セル分外へドラッグした、上ビューの地形](../assets/terrain/edge-drag.png)

ドラッグは、その辺のフィールドに入力してすぐに**適用**を押すのと同じ働きです。新しい地面は**端の高さ**と同じように端を引き継ぎ、地形が1セルより小さくなることはありません。

前ビューと横ビューでは左右の端だけをつかめます。地面の高さはスカルプトで決まるからです。**ゼロ**の地面や新しいセルサイズにしたいときは、**サイズ**ブロックに入力してください。

### 地形の上の散布 { #scatter-on-the-terrain }

地形の上にペイントした[散布](scatter.md)は、サイズを変えても地面に残ります。

* 残った地面の上のインスタンスは新しい高さに合わせて上下するので、浮いたり沈んだりしません。
* 切り取られた地面の上のインスタンスは、既定で削除されます。該当するものがあると、**適用**の下に**削除された範囲の散布インスタンスn個を削除**のチェックボックスが現れます。自分で動かすつもりなら、チェックを外すと、何もない所に浮いたまま、その場に残せます。
* 辺を内側へドラッグしたときは、必ず削除され、Ctrl+Zで戻ります。
* ロックされた、または非表示の散布セットや、ロックされた、または非表示のレイヤーにあるものは、そのままです。

## スカルプト { #sculpting }

Gを押し、左上のツールオプションバーの最初のメニューでモードを選んで、地形の上をドラッグします。選択した地形に作用し、何も選択していないときはすべての地形に作用します。

![スカルプトツールのモードメニューを、ツールオプションバーの半径と強さの欄の隣で開いたところ](../assets/terrain/sculpt-modes.png)

上げるでは、マウスボタンを押し続けるかぎり、ブラシの下で地面が上がり続けます。

![半径900ユニットのブラシで上げるを押し続けて、島から丘を作っているところ](../assets/terrain/sculpt-raise.gif)

| モード | 働き |
| --- | --- |
| 上げる、下げる | ボタンを押しているあいだ、高さを積み上げるか掘り下げます。クリックすると小さなこぶができます |
| スムーズ | 各頂点を隣の頂点に近づけてならし、でこぼこや鋭い尾根をやわらげます |
| 平坦化 | ストロークを始めた高さまで地面を引き寄せます。足場、道、台地を作るときに使います |
| ノイズ | 小さなランダムなこぶを足して、平らな地面を人工的に見えにくくします |
| 段丘 | 高さを**ステップ**ユニット刻み（既定は32）にそろえます。棚田や階段状の崖に向いています。このフィールドはモードの隣に表示されます |
| アルファを描く、アルファを消す、レイヤーを描く | 形を整える代わりにペイントします。アルファのモードはディスプレイスメント向けで、レイヤーを描くは、モードの隣の**レイヤー**フィールドで決めた地形レイヤーをペイントします。地形では、[ブレンドツール](terrain-painting.md)のほうが細かく制御できます |
| 穴、穴を塞ぐ | セルをまるごとくり抜いたり、埋め戻したりします。コリジョンも含みます。洞窟やバンカーの入口に使います。[洞窟とオーバーハング](caves-overhangs.md)を見てください |

Ctrl+ホイールでブラシの大きさが変わり、Shiftで上げると下げるが入れ替わり、Ctrlを押しているあいだは、どのモードでもスムーズになります。

オプションバーの**強さ**フィールドは、ブラシがどれくらい速く作用するかを決めます。上げると下げるは、**半径**にかかわらず、強さ1あたり毎秒8ユニットだけブラシの中心を動かすので、既定の4なら毎秒32ユニット積み上がります。丘や島なら、1分間押し続けるより強さを上げてください。

半径は地形のセルサイズより大きくしてください。それより小さいブラシは、その下にある頂点1つをつつくだけです（そうなったときはステータスバーが教えてくれます）。

最初からやり直すには、*地形 > スカルプト > 平坦化*か、インスペクターの**平坦化**で、選択した地形全体がゼロの高さに戻ります。

> [!TIP]
> 大きなブラシで形を作り、荒い作業のたびにスムーズをかけましょう。小さなブラシではこぶが残ります。

## 対称 { #symmetry }

谷や島の両側を一度にスカルプトするには、対称をオンにします。**スカルプト**と**ブレンド**の両方のツールにこのコントロールがあり、ツールオプションバーの**強さ**とモードのフィールドのすぐ後ろにあります。

![スカルプトツールのオプションバーで開いた対称メニュー。オフ、X、Z、X と Z が並んでいる](../assets/terrain/symmetry-menu.png)

| コントロール | 働き |
| --- | --- |
| **対称 オフ**メニュー | **X**を選ぶと西側と東側を互いに反転し、**Z**を選ぶと北側と南側を、**X と Z**を選ぶと両方を反転します。閉じたメニューには、そのあと**対称 X**、**対称 Z**、**対称 X と Z**と表示されます |
| **地形の中心**メニュー | 対称がオンのときだけ表示されます。鏡面の位置を決めます。**地形の中心**（各地形の中央）、**ワールド原点**、**カスタム**から選びます |
| **x**と**z**のフィールド | **カスタム**のときだけ表示され、反転する軸ごとに1つあります。鏡面の位置をユニットで指定します。最初は直前まで使っていた鏡面の位置になるので、急に動くことはありません |

対称がオンのとき、スカルプトかブレンドが有効なツールの間、ビューには鏡面が描かれます。Xは赤、Zは青のアウトラインです。各鏡面が地面と交わる所には線が沿い、押す前に、反転したブラシの跡がどこに落ちるかを薄い色のブラシリングが示します。

![対称 X と Z をオンにした3Dビュー。2つの鏡面と、4つの区画すべてに繰り返されたブラシリングが見える](../assets/terrain/symmetry-planes.png)

いつもどおりドラッグします。ブラシの操作ごとに、カーソルの位置とその反転位置の両方に適用され、ストローク全体は引き続き取り消し1回で戻ります。鏡面の上にある操作や、自分自身の反転と重なる操作は1回として数えるので、そこだけ地面が2倍の高さになることはありません。ノイズ、ブレンドノイズ、スプレーは、新しいランダムなパターンではなく、きちんとした鏡像になります。

**地形の中心**では、各地形が自分の中央を軸に反転し、ディスプレイスメントはすべてをまとめた中央を軸に反転します。スカルプトとブレンドは同じ設定を共有します。マップのタブごとに設定が残り、新しく作ったマップや開いたマップは使っていた設定を引き継ぎますが、**カスタム**は**地形の中心**に戻ります。エディターを起動するたびにオフに戻ります。

> [!TIP]
> 並んだ複数の地形をまたいで反転したいときや、地形の中央ではない場所を軸にしたいときは、**ワールド原点**か**カスタム**を使ってください。鏡面を頂点の並ぶ線の上か、2本の線のちょうど中間に置くとぴったり合います。それ以外の位置では、おおよその反転になります。

<div class="td-mcp" markdown>

`sculpt`アクション、`blend`ツール、`terrain_edit`（`sculpt`、`sculpt_path`、`paint_path`と、`center`を使う`holes`）は、`symmetry`引数を取ります。値は`off`、`x`、`z`、`xz`か、オブジェクト`{axes, center, x, z}`です。`set_editor`でツールバーが使う設定を指定でき、`get_state`で確認できます。[MCP](../mcp.md)を見てください。

## Godotで { #in-godot }

地形はすべて`TrenchDotTerrain`ノードになります。これは`StaticBody3D`（動かない固い地面のためのGodotのノード）で、当たり判定は描画されているものと一致します。ゲームプレイのコードでは、`height_at(x, z)`がローカル位置の地面の高さを返すので、実行時にものを地面に置くのに便利です。

## MCP { #mcp }

`terrain_edit`ツールの`sculpt`オペレーションは1回分のダブを適用し、その強さは、やはり半径にかかわらず、ダブがどれだけ中心を動かすかを表します。強さ4で1秒間ストロークを続けるのは、強さ32のダブと同じです。

同じサイズ変更は、`op: "resize"`を付けた`terrain_edit`です。セル単位の`north`、`south`、`west`、`east`か`cells: [x, z]`と、`cell_size`を取ります。`dry_run: true`を付けると、先に結果のセル数、範囲、`scatter_removed`、`detail_lost`を読めます。`fill`は`edge`か`zero`、`scatter`は`drop`か`keep`で、インスペクターと同じです。上限は[MCP](../mcp.md)を参照してください。

</div>
